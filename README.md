## How to run a program

1. Install JDK 17 or later.
2. Open the lab folder (for example `Lab01`) in Visual Studio Code with the Extension Pack for Java.
3. Open a file that has a `main` method and click **Run** above `main`.

Or from a terminal:

```
cd Lab01
javac Student.java
java Student
```
